# Portfolio demonstration script

1. Open the landing page and explain local-full versus public portfolio mode.
2. Register a workspace and show hashed-session authentication and role-based navigation.
3. Create a conversation, assign an agent, add a note and tag, and reply.
4. Upload a safe TXT/PDF/DOCX source or write an article, then index its chunks.
5. Ask the public chatbot a supported question and inspect the validated citation.
6. Ask an unsupported question to demonstrate refusal, then request human support.
7. Show AI suspension, agent suggestion controls, and the escalation email preview.
8. Open Analytics to explain real workspace-scoped data and insufficient-data labels.
9. Change a demonstration plan and show usage limits and activity history; emphasize that no charge occurs.
10. Open the development outbox and system status page, noting their owner-only authorization.
11. Conclude with the security model: tenant filtering in queries, private storage, hashed tokens, prompt-injection defense, and localhost-only Ollama.
